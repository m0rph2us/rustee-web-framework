Explicit API Description

OpenAPI는 route 구현을 추측하지 않습니다

rustee-openapi는 application이 선언한 Rustee route와 operation/schema를 검증해 OpenAPI 3.1 JSON을 제공합니다. handler signature, 인증 정책, 오류 의미와 domain schema는 application이 명시적으로 소유합니다.

선택 경계

  • facade에서는 rustee = { features = ["openapi"] }로 선택하고 rustee::openapi를 사용합니다. core/router에는 schema generator dependency를 추가하지 않습니다.
  • OpenApiRoute::from_rustee("/todos/:todo_id")는 Rustee parameter grammar를 검증해 /todos/{todo_id}로 변환합니다. document에 넣는 operation은 모든 route parameter를 required path parameter로 선언해야 합니다.
  • OpenApiSchema는 bounded JSON object만 받으며 string/integer/boolean/array/object/component reference helper를 제공합니다. model derive, reflection, router table scanning은 제공하지 않습니다.
  • OpenApiDocument::security_scheme는 named HTTP Basic/Bearer, API key(header/query/cookie), OpenID Connect discovery, Authorization Code/Client Credentials OAuth2와 mutualTLS component를 명시합니다. header API-key name은 HTTP field-name grammar를 따라야 하며 query/cookie name은 runtime parser를 소유하지 않는 bounded metadata입니다. OAuth endpoint와 discovery URL은 HTTPS 또는 loopback HTTP만 허용하고 credential/query/fragment를 거부합니다. OAuth requirement scope는 declared flow에 존재해야 하며 mutualTLS requirement에는 scope를 넣을 수 없습니다.
  • OpenApiDocument::global_security_requirement는 document-wide OR default를 선언합니다. operation은 local requirement로 이를 override하고, anonymous_access()의 {} alternative로 optional access를, clear_security_requirements()의 empty array로 inherited default removal을 명시합니다. runtime authorization은 생성하지 않습니다.
  • OpenApiDocument는 ordinary Rustee handler response로 반환됩니다. endpoint mount, document access policy, server URL, runtime authentication/authorization, error body와 release version은 application이 정합니다.

최소 경로

let document = OpenApiDocument::new("Todo API", "0.1.0")?
    .security_scheme(
        "oidc",
        OpenApiSecurityScheme::open_id_connect(
            "https://issuer.example/.well-known/openid-configuration",
        )?,
    )?
    .operation(
        OpenApiRoute::from_rustee("/todos/:todo_id")?,
        OpenApiMethod::Get,
        OpenApiOperation::builder("get_todo")
            .security_requirement(
                OpenApiSecurityRequirement::scoped("oidc", ["todos.read"])?
            )
            .path_parameter("todo_id", OpenApiSchema::integer())
            .json_response(StatusCode::OK, "The requested todo", todo_schema)
            .empty_response(StatusCode::NOT_FOUND, "The todo was not found")
            .build()?,
    )?;

let app = App::new()
    .get("/todos/:todo_id", get_todo)
    .get("/openapi.json", move || {
        let document = document.clone();
        async move { document }
    });

문서의 200 application/json 선언은 handler가 실제로 JSON response를 반환한다는 application contract입니다. security requirement도 같은 방식의 public contract입니다. framework가 이를 runtime에서 검사하거나 operation에서 handler, bearer verifier, session/OIDC login, API-key parser, tenant/scope policy를 자동 생성하지 않습니다.

검증과 비목표

  • unit/facade contract는 route 변환, required path parameter 누락/초과, duplicate parameter, response 누락, component reference, bounded schema, HTTP/API key/OIDC/OAuth2/mutualTLS security component, API-key header grammar, declared OAuth scope와 non-OAuth/OIDC scope 거부, global default/anonymous/clear override와 JSON content type을 확인합니다. route conversion은 property/fuzz contract도 갖습니다.
  • OpenAPI document는 static application metadata입니다. request payload, bearer credential, tenant/subject, prompt와 같은 runtime 데이터를 document에 넣지 않습니다.
  • Implicit/password OAuth flow, runtime token exchange/refresh/revocation, TLS termination, client-certificate validation/trust rotation/principal mapping, auth middleware inference, derive macro, OpenAPI UI hosting, server-variable templating, external schema validator와 route/document drift의 build-time discovery는 scope 밖입니다. 필요하면 provider interoperability와 failure policy를 포함한 ADR을 추가합니다.

관련 결정

public boundary는 ADR 0039와 ADR 0043과 ADR 0045, ADR 0046, ADR 0047을 따릅니다. release 상태는 지원 현황과 출하 계획이 기준입니다.
