현재 구현과 지원 약속을 구분합니다

이 표는 crate가 존재한다는 사실을 production support로 해석하지 않도록 하는 release inventory입니다. 단계의 정의는 출하 계획과 지원 정책을 따르며, 여기에는 실제 검증 증거와 다음 승격 조건만 기록합니다.

현재 선언

2026-08-04 현재 첫 intentional source baseline commit은 존재하지만 source tag와 published public API baseline은 없습니다. 그러므로 어떤 crate도 Supported 또는 Enterprise-qualified로 선언하지 않습니다. 이 매트릭스의 Contract-verified는 특정 backend 또는 protocol contract가 존재한다는 뜻이지, 일반적인 production topology를 보증한다는 뜻이 아닙니다.

갱신 규칙

  • 새 crate는 이 표에 Experimental로 추가하고, public/publish intent와 non-goal을 같은 변경에 기록합니다.
  • Contract-verified 승격에는 실제 transport/backend command와 pinned provider version을 테스트 전략에 연결합니다.
  • Supported 또는 Enterprise-qualified 승격에는 ADR, version matrix, failure/upgrade/rollback evidence를 추가합니다.
  • 코드, CI, provider version, release blocker가 바뀌면 이 표와 구현 계획 재검토를 같은 변경에서 갱신합니다.
