Support Matrix

Separate Framework Contracts from Adopter Deployment Evidence

This matrix describes the reusable Rustee framework. An adopter earns an Enterprise-qualified deployment claim only after it supplies evidence for its selected provider and topology.

Current Declaration

The documented core framework baseline has targeted automated verification. Optional persistence, security, job, event, AI, MCP, and edge integrations have contract-specific implementation, tests, and runbooks. Provider and topology evidence is intentionally owned by each adopter rather than assumed by this repository.

Update Rules

  • Update framework status when its documented contract, automation, or runbook changes.
  • Each adopter records provider version, topology, scope, date, owner, and expiry in its qualification register.
  • Downgrade or annotate a deployment claim when its evidence expires, its supported version changes, or a critical behavior is unverified.
  • Do not infer an adopter's support claim from compilation, a single test, or a local container run.
