Release Governance

Workspace release inventory

이 목록은 Cargo workspace의 모든 package에 공개 후보 또는 workspace-only 의도를 명시합니다. 실제 publish 승인은 지원 단계와 release checklist를 통과한 뒤 별도로 이루어집니다.

검증 규칙

  • scripts/check-release-inventory.mjs가 이 문서 안의 JSON inventory와 cargo metadata를 비교합니다.
  • 공개 후보는 description, SPDX license expression, HTTPS repository, Rust 2024/MSRV 1.94.1, library 또는 procedural-macro target과 versioned local dependency를 가져야 합니다. verifier는 repository-level Apache/MIT legal artifact도 확인합니다.
  • workspace-only package는 publish = false여야 합니다. candidate는 release 승인 전에도 publish를 실행하지 않습니다.
  • node scripts/package-release-candidates.mjs는 inventory-approved candidate만 source archive로 만들고 workspace-only package와 stale archive를 제외한 exact artifact set을 검증할 뿐 registry에 업로드하지 않습니다.

승인 경계

이 inventory는 publish permission이 아니라 package ownership을 선언합니다. 첫 source tag와 human API review가 baseline을 만들고, 이후에는 출하 계획의 gate, 지원 현황, release notes와 migration guidance가 실제 release 결정을 뒷받침합니다.
