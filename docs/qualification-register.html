Qualification Register

외부 증거가 필요한 gate를 코드 완료와 분리해 추적합니다

이 register는 credential, billing, named deployment topology 또는 publish authority가 필요한 항목의 작업 기준입니다. CI, package dry-run, local adapter test가 통과해도 여기의 required evidence가 없으면 support level이나 release status를 올리지 않습니다.

현재 상태

2026-08-04 현재 첫 intentional source baseline commit은 존재하지만, source tag/publish baseline과 chosen CDN 또는 live-provider deployment qualification은 기록되지 않았습니다. 이 표의 모든 항목은 Needs explicit owner action입니다. Draft 문서, ignored test 또는 local package diagnostic은 완료 record가 아닙니다.

완료 record의 최소 필드

  • gate ID, date, responsible owner, reviewed Rustee/source version과 environment classification
  • redacted configuration revision or immutable deployment identifier, exact test/workflow/runbook reference와 result
  • observed failure/recovery or explicit non-applicability, rollback/reconciliation decision과 alert owner
  • expiration or requalification trigger: provider version, topology, credential trust, cache policy, public API 또는 recovery procedure가 바뀌면 record를 다시 검토합니다.

갱신 규칙

owner가 required evidence를 승인한 뒤에만 이 register의 상태를 completed로 바꾸고, 같은 change에서 support matrix, release notes, relevant ADR/testing/operations document를 갱신합니다. evidence가 만료되거나 topology가 달라지면 prior Supported claim을 유지한 채 방치하지 않고 해당 integration을 재검토 상태로 내립니다.
