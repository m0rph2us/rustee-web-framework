Architecture Decision Record

ADR 0008: AI Application Integration Boundary

Status: Accepted

Context

AI applications need provider calls, retrieval, tools, streams, and evaluation while treating model and retrieved content as untrusted input.

Decision

Provide optional provider-neutral pipeline contracts with final-request policy, verified context, budget reservation, typed tools, approval, audit, redaction, RAG ACL revalidation, and provider adapters.

Consequences

Rustee does not own prompts, API keys, vector stores, automatic agent loops, domain authorization, billing, or external side effects. Live provider and data-policy qualification are separate release gates.
