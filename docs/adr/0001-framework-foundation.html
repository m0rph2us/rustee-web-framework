ADR 0001: Framework Foundation

Status: Accepted

Context

Rustee needs a beginner-friendly HTTP API that can grow into operational and enterprise use without becoming a monolithic replacement for the Rust ecosystem.

Decision

Build a small typed core around requests, responses, handlers, extractors, state, and error conversion; use Tokio and Hyper for transport; remain Tower-compatible for service and middleware composition; place integrations in optional focused crates.

Consequences

The public facade remains simple while applications can compose established ecosystem components. Database, identity, queue, AI, and deployment choices are not core dependencies and require their own support contracts.
