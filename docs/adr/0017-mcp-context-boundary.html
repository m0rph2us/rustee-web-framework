Architecture Decision Record

ADR 0017: MCP Context Boundary

Status: Accepted

Context

MCP resources, templates, prompts, and notifications can contain sensitive or untrusted context that should not automatically affect model input.

Decision

Expose bounded capability-gated discovery/read APIs and require application/user selection, authorization, redaction, and token-budget policy before any returned context reaches a provider request.

Consequences

Rustee does not auto-inject MCP context or notifications. Applications own selection, retention, classification, and prompt composition.
