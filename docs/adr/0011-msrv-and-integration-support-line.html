Architecture Decision Record

ADR 0011: MSRV and Integration Support Line

Status: Accepted

Context

A published framework needs a clear Rust-version and optional-integration support policy.

Decision

Maintain Rust 1.94.1 as the current MSRV and test it in CI. Optional integrations declare their own feature, native dependency, provider-version, and qualification requirements.

Consequences

An adapter is not supported merely because the workspace compiles. MSRV or dependency changes require release notes, migration guidance, and matrix review.
