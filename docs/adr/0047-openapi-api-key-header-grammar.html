Architecture Decision Record

ADR 0047: OpenAPI API-Key Header Grammar Boundary

Status: Accepted

Context

API-key documentation must accept only valid HTTP header names and must not confuse a header grammar with authentication enforcement.

Decision

Validate explicit API-key header names against the supported HTTP token grammar when creating OpenAPI security metadata.

Consequences

Invalid documentation fails early. Runtime key extraction, validation, storage, and authorization stay in the authentication layer.
