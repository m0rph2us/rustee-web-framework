Architecture Decision Record

ADR 0045: OpenAPI OAuth2 and Global Security Boundary

Status: Accepted

Context

OAuth2 flows and global security declarations need accurate API documentation without coupling to deployment authorization configuration.

Decision

Support explicit static OAuth2 flow metadata and document-level security requirements with explicit operation overrides.

Consequences

Scopes, endpoints, client registration, issuer trust, and runtime enforcement stay application- and deployment-owned.
