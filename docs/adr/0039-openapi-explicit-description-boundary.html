Architecture Decision Record

ADR 0039: OpenAPI Explicit Description Boundary

Status: Accepted

Context

Route registration alone does not reveal public operation meaning, schemas, errors, descriptions, or security policy.

Decision

Require explicit operation descriptions and schema/security metadata in the optional OpenAPI builder while validating route-pattern conversion.

Consequences

Documentation stays accurate through intentional application ownership, but developers provide metadata rather than relying on unsafe inference from handler implementation.
