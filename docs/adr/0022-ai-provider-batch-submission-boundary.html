Architecture Decision Record

ADR 0022: AI Provider Batch Submission Boundary

Status: Accepted

Context

Provider batch submission must survive duplicate job delivery and ambiguity without placing raw model content in durable framework records.

Decision

Use content-free tenant scope, catalog/run-key references, atomic reservation, receipt reuse, application catalog loading, and one-time provider submission/receipt recording.

Consequences

Catalog authorization, actual request content, retry/DLQ, billing, retention, and provider operation remain application-owned. Pending ambiguity never causes automatic replay.
