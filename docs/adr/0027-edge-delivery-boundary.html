Architecture Decision Record

ADR 0027: Edge Delivery Boundary

Status: Accepted

Context

Public TLS, CDN cache, purge, compression, and origin routing are infrastructure behavior, not origin transport behavior.

Decision

Keep Rustee at the origin and define edge delivery as explicit deployment policy with restricted proxy trust, cache variation, purge, drain, rollback, and qualification evidence.

Consequences

Rustee does not implement a CDN adapter or claim public edge support from local tests. Deployment owners qualify provider topology and incidents.
