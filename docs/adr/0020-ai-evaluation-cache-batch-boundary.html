Architecture Decision Record

ADR 0020: AI Evaluation, Cache, and Batch Boundary

Status: Accepted

Context

Evaluation, response caching, and provider batch operations need durable references and policy boundaries without storing raw model content by default.

Decision

Provide separate optional evaluation, exact-key cache, and batch-control contracts using bounded, content-free references, explicit TTL/retention, durable reservation, and application-selected processors.

Consequences

Grader trust, cache fingerprinting, data erase, domain idempotency, billing, partial output, and provider lifecycle qualification remain application responsibilities.
