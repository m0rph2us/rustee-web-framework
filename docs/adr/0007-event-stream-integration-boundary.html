ADR 0007: Kafka Event Stream Integration Boundary

Status: Accepted

Context

Kafka is a partitioned event log with keys, offsets, consumer groups, and replay semantics that differ from a job queue.

Decision

Provide versioned event envelopes, explicit topic/key, manual post-settlement commit, retry/DLQ routing, bounded observability, schema artifacts, and optional PostgreSQL delayed retry. Keep replay an operator-approved process.

Consequences

Kafka behavior is at least once across crash boundaries. Topic provisioning, partitions, ACLs, schema rollout, external-effect idempotency, replay, and provider qualification remain deployment-owned.
