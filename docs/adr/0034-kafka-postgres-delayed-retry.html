Architecture Decision Record

ADR 0034: Kafka PostgreSQL Delayed Retry

Status: Accepted

Context

Kafka retry topics do not provide durable scheduled delivery, and a source record must not commit until retry intent is safely recorded.

Decision

Stage retry intent in PostgreSQL using the database clock before source offset commit. Lease due rows with SKIP LOCKED and confirm only after Kafka acknowledges the retry publish.

Consequences

Kafka and PostgreSQL confirmation are not atomic, so duplicate retry publication remains possible. Migration, topic provisioning, backoff, replay, and idempotency remain external responsibilities.
