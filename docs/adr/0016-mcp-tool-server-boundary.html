Architecture Decision Record

ADR 0016: MCP Tool Server Boundary

Status: Accepted

Context

An MCP server exposes application capabilities to model-connected clients and requires browser-origin, access, approval, and audit controls.

Decision

Mount an optional JSON-response MCP server with fail-closed Origin validation, access-filtered discovery, application-created execution context, approval, and mandatory terminal audit before tool execution.

Consequences

Applications own authentication, authorization policy, tools, side effects, context retention, and server lifecycle. Server-initiated requests, sampling, elicitation, subscriptions, and completion remain out of scope.
