Architecture Decision Record

ADR 0030: PostgreSQL Scheduler Rate Governor

Status: Accepted

Context

Recurring schedules can need a shared durable rate boundary that is atomic with outbox materialization.

Decision

Offer an opt-in PostgreSQL-clock fixed-window governor. A due schedule consumes capacity in the same transaction; without capacity it advances to the next window without creating an outbox row. Application-owned schedule and shared-governor keys stay available only through their explicit storage contracts and are redacted from framework diagnostics.

Consequences

This is separate from HTTP rate limiting and does not provide fairness, daily quota, external-provider quota, or global distributed scheduling policy.
