Architecture Decision Record

ADR 0041: routes Builder Macro Boundary

Status: Accepted

Context

Route declaration syntax can be made more concise without creating an alternative routing system.

Decision

Provide optional routes! syntax that generates normal App route-builder calls and validates supported forms at compile time.

Consequences

Macro-free routing remains first-class. The macro does not infer state, policies, schemas, error handling, or security requirements.
