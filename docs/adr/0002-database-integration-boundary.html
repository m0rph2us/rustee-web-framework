ADR 0002: Database Integration Boundary

Status: Accepted

Context

Web services need relational persistence, but a core framework-owned ORM or repository API would restrict database-specific capabilities and application choice.

Decision

Keep database access optional. Use SQLx as the first official relational integration, inject pools through application state, preserve SQLx types, and expose explicit transaction and PostgreSQL tenant-RLS helpers.

Consequences

Applications own drivers, ORM/toolkit choice, migrations, schema, credentials, pool settings, and topology. PostgreSQL outbox/inbox support remains a separate optional adapter with at-least-once delivery semantics.
