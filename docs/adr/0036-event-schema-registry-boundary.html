Architecture Decision Record

ADR 0036: Event Schema Registry Boundary

Status: Accepted

Context

Schema registry publication must verify an exact source-controlled artifact and declared policy without pretending to prove semantic compatibility or control Kafka.

Decision

Use typed JSON Schema artifacts with exact fingerprints and stable subject/version catalogs. The Confluent adapter checks effective policy, exact lookup, absent registration, and exact relookup through bounded redacted transport.

Consequences

The adapter does not publish events, inject headers, create topics, move offsets, or infer compatibility. Consumer-first rollout, rollback, replay, and live provider evidence remain deployment-owned.
