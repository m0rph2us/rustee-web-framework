Architecture Decision Record

ADR 0052: CORS Origin Admission Boundary

Status: Accepted

Context

CORS is a browser interoperability response policy, not authentication or authorization. A layer that attaches configured CORS headers without validating the request Origin leaves its actual admission and cache behavior implicit.

Decision

CorsLayer accepts exactly one request Origin whose header value equals its configured origin. It short-circuits only matching preflight requests, applies actual-response and preflight-response headers separately, and adds Vary: Origin without duplicating an existing variation. Missing, unmatched, or duplicate Origin input passes to the inner service unchanged.

Consequences

Applications retain endpoint authorization, CSRF policy, allowed method selection, cache deployment, and error behavior for non-CORS requests. An application needing more than one origin or dynamic tenant policy provides a focused, explicit layer rather than relying on wildcard inference.
