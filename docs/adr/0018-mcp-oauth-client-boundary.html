Architecture Decision Record

ADR 0018: MCP OAuth Client Boundary

Status: Accepted

Context

MCP client authorization needs discovery, PKCE, one-time state, token protection, and a strict no-replay relationship with tool calls.

Decision

Provide a separate OAuth client with protected-resource/authorization-server discovery, PKCE S256, atomic state/verifier consumption, canonical resource binding, redacted token handling, and optional encrypted Redis persistence. Redis record identity is versioned and length-delimited across the configured namespace and opaque transaction state or token slot, while the complete record key remains authenticated-encryption data.

Consequences

Client registration, consent, KMS, revocation, refresh coordination, provider trust, and live qualification remain application or deployment responsibilities.
