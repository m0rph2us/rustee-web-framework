Architecture Decision Record

ADR 0048: API-Key Header Authentication Boundary

Status: Accepted

Context

Service API keys need a narrow transport contract that avoids accidental query/cookie use and preserves sanitized authentication failures.

Decision

Provide an explicit header-only API-key authentication layer that normalizes verified keys into Principal and applies scope/authorization policy separately.

Consequences

Issuance, UX, transport policy beyond the header, storage, rotation, pepper management, and operational response remain application-owned.
