Architecture Decision Record

ADR 0042: TestApp Cookie Jar Boundary

Status: Accepted

Context

In-process session and CSRF tests need browser-like cookie continuity without pretending to be a full browser implementation.

Decision

Add an explicit TestApp cookie jar that processes supported response cookie attributes and supplies eligible request cookies in tests.

Consequences

The helper is deterministic test infrastructure, not browser compatibility or production cookie policy. Complex browser behavior remains outside its contract.
