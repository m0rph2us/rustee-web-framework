ADR 0004: MongoDB Integration Boundary

Status: Accepted

Context

Document persistence needs the MongoDB driver's native document, aggregation, transaction, and change-stream capabilities without leaking BSON as an HTTP model.

Decision

Use the official MongoDB Rust driver in an optional adapter, inject Client through application state, preserve BSON/HTTP DTO separation, and provide explicit transaction, tenant-scope, readiness, shutdown, and checkpoint helpers.

Consequences

Applications own schemas, validators, indexes, migrations, topology, and raw-driver administrative access. Tenant scopes are application-layer safeguards, not server-enforced MongoDB RLS, and change-stream handlers remain at least once.
