ADR 0009: Testing and Verification Strategy

Status: Accepted

Context

Framework correctness depends on observable HTTP, cancellation, provider, recovery, and feature-combination behavior, not line coverage alone.

Decision

Use layered deterministic unit, in-process, transport, property/fuzz, container-contract, and external-qualification tests with explicit feature and platform lanes.

Consequences

Provider-specific semantics require real-backend contracts; local containers and mocks do not establish managed-provider or production-topology support. Flaky tests are fixed rather than hidden by retry.
