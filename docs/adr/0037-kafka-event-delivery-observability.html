ADR 0037

Kafka Event Delivery Observability

Kafka source settlement lifecycle을 aggregate-only로 관찰하되, topic·offset·replay 운영 권한은 application deployment에 둡니다.

Status: Accepted | Date: 2026-08-04

Context

Kafka event consumer는 handler success, failure route broker acknowledgement, source offset commit, rebalance와 cancellation이 서로 다른 at-least-once 결과를 만듭니다. handler return만 집계하면 route 또는 commit failure를 success로 오인하고, topic/partition/offset/event ID/error를 metric label로 넣으면 cardinality와 payload/endpoint leakage 위험이 생깁니다. delayed-retry relay에는 pass observability가 있지만 일반 consumer delivery의 source settlement는 별도 lifecycle이 필요합니다.

Decision

rustee-events에 panic-isolated, cancellation-safe EventDeliveryObserver와 EventDeliveryObservation을 둡니다. Kafka adapter는 record를 받은 뒤 observation을 시작하고, source offset commit이 성공한 뒤에만 acknowledged, retried, dead_lettered를 finish합니다. decode/handler/route/commit failure와 task cancellation은 unsettled로 종료합니다.

rustee-events-observability는 bounded provider/outcome, in-flight, global duration collector이고, rustee-events-observability-prometheus는 explicit Prometheus text 0.0.4 Cache-Control: no-store response helper입니다. application이 collector 연결, scrape route/isolation, alert/retention과 incident policy를 소유합니다.

Consequences

  • observer result는 handler outcome이 아니라 consumer가 관찰한 source settlement입니다. acknowledged/retried/dead-lettered는 external side effect exactly-once 또는 replay safety를 증명하지 않습니다.
  • metric label은 bounded provider와 fixed outcome뿐입니다. topic, partition, consumer group, offset, event ID/type/version, key, payload, trace carrier, tenant, endpoint와 raw error는 collector와 Prometheus text에 넣지 않습니다.
  • observer panic은 억제되고 source commit/failure route semantics를 바꾸지 않습니다. unfinished observation의 drop은 unsettled이며 exporter implementation은 synchronous aggregate 또는 bounded handoff만 수행해야 합니다.
  • global registry, listener, automatic /metrics route, broker/lag probe, alert threshold, retry/backoff, source group offset modification과 DLQ replay command는 제공하지 않습니다.
  • real Kafka contract는 successful source commit 뒤 acknowledged, retry/DLQ route 및 source commit 뒤 retried/dead-lettered, in-flight rebalance 뒤 source commit failure의 unsettled를 검증합니다. broker container가 없는 local default test는 이를 실행하지 않으며 CI/native qualification이 담당합니다.

Alternatives

대안판단
handler return 직후 success metric 기록Kafka source commit과 failure-route persistence failure를 감추므로 채택하지 않습니다.
topic/partition/offset/error를 Prometheus label로 사용unbounded cardinality와 operational detail leakage를 만들므로 채택하지 않습니다.
Kafka crate 안에 global exporter와 automatic route 제공scrape authorization, topology, alert owner를 generic adapter가 결정하게 되므로 채택하지 않습니다.
observer가 DLQ를 자동 replay하거나 offset을 이동incident approval, side-effect idempotency와 reconciliation boundary를 무너뜨리므로 채택하지 않습니다.
