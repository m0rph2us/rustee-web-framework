Architecture Decision Record

ADR 0049: Keyed API-Key Fingerprint Store Boundary

Status: Accepted

Context

API-key verification needs durable lookup without storing raw keys or exposing reversible identity material.

Decision

Use keyed HMAC-SHA-256 fingerprints and a provider-neutral store boundary with explicit active, expiry, revocation, rotation, and verified-principal metadata.

Consequences

Peppers, KMS delivery, record retention, audit, migration, and database outage policy are application/deployment responsibilities. Fingerprints are not credentials or authorization by themselves.
