Architecture Decision Record

ADR 0046: OpenAPI Mutual TLS Metadata Boundary

Status: Accepted

Context

Mutual TLS may be part of a public API contract even when TLS termination occurs outside the Rustee process.

Decision

Allow explicit OpenAPI mutual-TLS security metadata without adding transport certificate verification to the document builder.

Consequences

Ingress certificate validation, proxy identity, client-certificate policy, and deployment evidence remain infrastructure responsibilities.
