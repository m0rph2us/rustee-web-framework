Architecture Decision Record

ADR 0023: OpenAI Batch Lifecycle Adapter

Status: Accepted

Context

OpenAI Batch uses files and lifecycle operations that need bounded transport, typed conversion, and redaction without embedding provider business policy.

Decision

Provide bounded upload, download, delete, create, retrieve, cancel, structural JSONL parsing, typed Responses/Embeddings conversion, and category-only diagnostics for source-carrying public conversion errors in an optional adapter.

Consequences

Provider fields, model selection, live credentials, lifecycle polling, data policy, billing, output meaning, and spend approval remain application responsibilities.
