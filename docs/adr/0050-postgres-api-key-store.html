Architecture Decision Record

ADR 0050: PostgreSQL Keyed API-Key Store

Status: Accepted

Context

The generic fingerprint-store contract needs an optional operational PostgreSQL implementation with safe rotation and audit behavior.

Decision

Provide rustee-auth-sqlx with PostgreSQL keyed fingerprint records, bounded readiness, source-overlap metadata cloning, no-overlap rotation/revocation, expiry, and atomic successful-auth audit.

Consequences

Deployment owns migration, database policy, peppers/KMS, principal JSON evolution, retention, backups, and recovery. The store remains optional and fail-closed on unavailability. Its public storage diagnostics retain only a failure category; trusted SQL sources remain available to application handling.
