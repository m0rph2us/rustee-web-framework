ADR 0010: Platform Foundation and Deployment Trust

Status: Accepted

Context

Production services need configuration, lifecycle, health, proxy trust, metrics, redaction, and deployment boundaries before optional feature growth.

Decision

Provide typed configuration and redaction, explicit trusted-proxy normalization, graceful lifecycle guidance, bounded observability, optional Prometheus/OpenTelemetry adapters, compression, and an opt-in panic response boundary.

Consequences

Applications own TLS, edge/CDN policy, secrets, alerting, scrape routes, exporter configuration, supervisor behavior, and production topology. Client-supplied forwarding is never trusted by default.
