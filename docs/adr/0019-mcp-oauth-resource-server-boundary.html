Architecture Decision Record

ADR 0019: MCP OAuth Resource-Server Boundary

Status: Accepted

Context

An MCP server needs standard protected-resource metadata and a reliable bearer challenge without taking ownership of the deployment's authorization server.

Decision

Provide public protected-resource metadata, fail-closed 401/403 Bearer challenge and scope behavior, and verified principal handoff to the application.

Consequences

Token issuance, storage, refresh, verification settings, audience/issuer trust, and authorization-server policy remain external to the crate.
