Architecture Decision Record

ADR 0044: Route and OpenAPI Parser Property and Fuzz Boundary

Status: Accepted

Context

Route and OpenAPI grammar parse untrusted application input and need more coverage than hand-picked examples. Route declarations that silently collapse repeated path separators can disagree with upstream routing, caches, or externally documented paths.

Decision

Use property tests for documented invariants and independent libFuzzer targets with seed corpora for route and OpenAPI parsing. Both Rustee route declarations and OpenAPI route conversion reject repeated path separators, and router matching does not collapse them at request time.

Consequences

Fuzzing complements deterministic regression cases and supported-platform CI; it does not establish semantic route or API correctness by itself. Applications configure one unambiguous route template and may apply any deliberate external path canonicalization before Rustee dispatch.
