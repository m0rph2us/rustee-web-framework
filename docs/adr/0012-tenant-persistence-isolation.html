Architecture Decision Record

ADR 0012: Tenant Persistence Isolation

Status: Accepted

Context

Route authorization does not ensure that persistence reads and writes remain inside a verified tenant boundary.

Decision

Use provider-neutral TenantContext created from verified identity or trusted routing. Its non-blank, NUL-free value is bounded to 1 KiB before it reaches a persistence adapter. PostgreSQL helpers set a transaction-local tenant setting for application-owned RLS; MongoDB helpers apply trusted tenant filters and document checks.

Consequences

Applications still own repository coverage, database policy, raw-driver access, indexes, and tenant A/B contract tests. Client headers and body fields never create tenant authority.
