Architecture Decision Record

ADR 0015: MCP Remote Tool Boundary

Status: Accepted

Context

A remote MCP transport can fail or reconnect around a tool call, making implicit replay unsafe.

Decision

Provide bounded Streamable HTTP and stdio discovery/call clients. Session recovery and SSE resumption may establish a new or GET-only path but never automatically replay a discovery, read, prompt, or tool call.

Consequences

Applications select tools, context, approval, retry authority, credentials, and transport lifecycle. Failures remain visible to the caller for policy-driven handling.
