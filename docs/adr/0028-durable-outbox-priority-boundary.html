Architecture Decision Record

ADR 0028: Durable Outbox Priority Boundary

Status: Accepted

Context

Some durable outbox messages need local relay preference without implying broker-wide fairness or priority semantics.

Decision

Store optional 0-255 priority before staging. For an eligible kind and destination, claim higher priority first and preserve durable FIFO order for equal priority.

Consequences

Priority is local PostgreSQL relay ordering only. It does not guarantee broker order, tenant fairness, global rate limiting, or starvation prevention.
