Architecture Decision Record

ADR 0032: Job Delivery Prometheus Exporter Boundary

Status: Accepted

Context

Workers need metrics, but job identifiers and payload-related data create unbounded or sensitive metric cardinality.

Decision

Collect only bounded provider, settlement outcome, and global duration. Supply an optional explicit Prometheus text response helper without a global registry, listener, or automatic route.

Consequences

Job ID/type, payload, queue, receipt, idempotency key, trace carrier, and raw error remain outside metrics. Applications own export, alerts, and correlation policy.
