Architecture Decision Record

ADR 0038: AI Evaluation Durable Run Boundary

Status: Accepted

Context

Evaluation can need durable scheduling and reporting but raw suites, prompts, completions, and grader data should not become generic job payload or ledger content.

Decision

Use catalog/run-key-bound references, a reference-only durable job, and a PostgreSQL pending/completed ledger. Evaluation is bounded, sequential, and stops after executor or grader failure.

Consequences

Human/LLM grader trust and spend, baseline comparison, report retention, live providers, and retry decisions remain application policy. Pending ambiguity does not trigger automatic re-evaluation.
