Architecture Decision Record

ADR 0043: OpenAPI Security Metadata Boundary

Status: Accepted

Context

API documents need security requirements, but documentation metadata must not configure or imply live authentication behavior.

Decision

Expose explicit OpenAPI security scheme and operation/global requirement builders separate from Rustee authentication middleware.

Consequences

Applications own consistency between documentation and enforcement. Metadata does not verify tokens, issue credentials, or determine authorization.
