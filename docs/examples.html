Rustee 공식 예제

각 예제는 workspace-only package로 매 pull request에 compile하며, 대표 public flow는 in-process test로 고정합니다. 여기의 예제는 provider 운영 자격이나 배포 topology를 대신하지 않습니다.

예제 맵

package경로와 기본 실행대표 contract명시적 한계
hello-worldexamples/hello-world, port 3000JSON greeting과 explicit OpenAPI documentapplication schema와 deployment policy는 사용자가 소유
json-apiexamples/json-api, port 3001typed path/query/JSON/state, 201 response와 invalid inputdatabase persistence와 authorization은 포함하지 않음
middleware-exampleexamples/middleware, port 3002explicit CORS, request ID, panic boundary, compression orderproxy trust와 production panic policy는 deployment가 선택
security-jwtexamples/security-jwt, port 3003, JWT_HMAC_SECRETHMAC JWT verified principal과 missing bearer challengeOIDC/JWKS, key rotation, issuer outage qualification은 포함하지 않음
jobs-exampleexamples/jobstyped envelope, idempotency key, publish와 registry dispatchlocal publisher는 durable broker, ack, retry, DLQ가 아님
ai-pipelineexamples/ai-pipeline, port 3004, OPENAI_API_KEY, OPENAI_MODELdeployment-configured provider model, AI pipeline, response mapping, failure redactionrecorded test provider는 live spend, tenant/budget/retention gate가 아님

검증과 실행

cargo +1.94.1 test -p hello-world -p json-api -p middleware-example -p security-jwt -p jobs-example -p ai-pipeline --offline
cargo +1.94.1 run -p json-api
cargo +1.94.1 run -p middleware-example
JWT_HMAC_SECRET=change-me cargo +1.94.1 run -p security-jwt
cargo +1.94.1 run -p jobs-example
OPENAI_API_KEY=... OPENAI_MODEL=your-provider-model-id cargo +1.94.1 run -p ai-pipeline

ai-pipeline의 run command만 real OpenAI provider request를 만들 수 있습니다. OPENAI_MODEL은 adapter에 전달할 provider model ID이며 application alias를 자동 해석하지 않습니다. live credential, spending limit, tenant policy, output retention과 provider outage handling을 검증할 때는 AI application integration과 release qualification을 함께 따릅니다.

변경 규칙

예제의 public API, 환경 변수, 검증 flow 또는 package 이름을 바꾸면 이 문서와 구조, 테스트 전략, 로드맵, release inventory, 관련 기능 문서를 같은 변경에서 갱신합니다. 전체 규칙은 AI 유지관리에 있습니다.
