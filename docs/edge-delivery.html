Edge Delivery Policy

CDN은 Rustee의 transport가 아니라 명시적 배포 계약입니다

Rustee origin은 cleartext HTTP/1.1과 explicit proxy trust를 제공합니다. TLS, WAF, edge cache, purge와 origin shielding은 chosen CDN 또는 reverse proxy가 소유하며, application은 그 구성을 검증 가능한 deployment artifact로 남깁니다.

기본 결정

framework는 CDN SDK, global purge API, certificate manager 또는 generic cache facade를 제공하지 않습니다. 배포는 하나의 named edge vendor와 versioned configuration을 선택하고, Rustee에는 edge의 direct peer CIDR만 trusted proxy로 설정합니다. client에서 온 Forwarded/X-Forwarded-* header는 edge가 선택한 하나의 family로 overwrite한 값만 origin에 전달합니다.

이 정책은 운영 계약의 reverse-proxy trust와 ADR 0010을 구체화합니다. local Nginx contract는 framework-origin interoperability 증거이며, vendor CDN의 TLS, purge, IAM 또는 cache behavior를 보증하지 않습니다.

Purge와 변경 절차

  1. asset은 content-addressed 또는 fingerprinted URL을 우선합니다. mutable URL purge는 application의 release workflow가 vendor API를 직접 호출하며 Rustee crate가 호출하지 않습니다.
  2. purge request는 named scope, operator identity, reason, deployment version과 result를 audit합니다. wildcard 또는 whole-zone purge는 incident procedure에서만 별도 승인으로 허용합니다.
  3. cache header, compression owner, key rule, origin route, certificate 또는 proxy CIDR을 바꾸면 canary URL에서 hit/miss, representation, authorization bypass, rollback을 먼저 검증합니다.
  4. origin drain은 edge가 새 request를 해당 origin으로 보내지 않게 만든 뒤 시작합니다. Rustee readiness false와 graceful timeout은 edge health/removal timeout보다 짧아지지 않게 deployment에서 조정합니다.

Supported 승격 증거

vendor를 선택한 deployment가 edge-delivered production support를 주장하려면 다음 evidence를 release record에 연결합니다.

  • vendor, region/topology, configuration revision, public hostname, certificate renewal owner와 origin firewall/CIDR allowlist를 식별합니다. secret과 private endpoint는 기록하지 않습니다.
  • untrusted direct client header가 edge에서 overwrite되고, edge만 origin에 도달할 수 있으며 Rustee가 그 peer만 trust하는 integration test를 수행합니다.
  • public asset의 miss/hit/revalidation, identity/gzip/Brotli representation separation, authenticated/cache-bypass response, Range/HEAD/no-transform과 cache purge 또는 fingerprint rollout을 실제 edge에서 확인합니다.
  • certificate failure/renewal alert, origin outage, health probe, traffic drain, rollback, edge cached error behavior와 alert owner를 game day 또는 equivalent failure test로 확인합니다.
  • edge request/cache/purge/certificate telemetry에서 token, cookie, authorization header, raw query, prompt/body가 retention 대상이 아님을 확인합니다.

명시적 비목표

이 문서는 CloudFront, Cloudflare, Fastly, Akamai, Nginx 또는 특정 load balancer를 Supported로 선언하지 않습니다. multi-CDN failover, universal surrogate-key API, direct TLS/HTTP/2 origin server, automatic certificate renewal과 framework-driven cache purge는 별도 topology ADR과 provider evidence 없이는 범위 밖입니다.
