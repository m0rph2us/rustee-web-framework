Static File Delivery

Serve Static Files Safely Outside Application Routes

rustee-static is an optional, prefix-bound Tower layer for filesystem delivery. It does not transform a source directory into general application routing or a CDN.

Usage Boundary

  • Mount static content below an explicit static prefix; direct application routes retain their normal precedence.
  • Configure the root, index behavior, cache policy, and missing-file response explicitly.
  • Do not expose arbitrary filesystem paths, symlinks outside the approved root, or deployment secrets through a static mount.

Response Contract

  • Set MIME type from a controlled mapping and emit weak ETag and Last-Modified validators where eligible.
  • Handle conditional requests before opening or streaming unnecessary content.
  • Support single and multipart byte ranges within bounded parsing and response limits. Unknown range units are ignored as full representations, while malformed byte-range sets receive the normal unsatisfied-range response. Keep range parsing and normalization separate from filesystem traversal and response streaming.
  • Precompressed variants are opt-in and negotiate their own encoding/cache representation.
  • Large files use bounded streaming rather than unbounded memory buffers.

Filesystem Security

  • Normalize and validate request paths under the configured root before file access.
  • Reject traversal, malformed percent encoding, and unsafe path resolution.
  • Configuration diagnostics report content-free categories by default while retaining trusted I/O sources for application handling. Configuration and layer debug output exposes policy state without root, mount, or raw header values.
  • Review symlink, file-permission, container-volume, and deployment-user policy together; a routing layer cannot make an unsafe filesystem safe.

Out of Scope

CDN cache keys, public TLS, image transformation, uploads, object storage, access authorization, purge, and global replication are deployment or application concerns. See the edge delivery policy for that boundary.
