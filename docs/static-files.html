Static File Delivery

정적 파일은 애플리케이션 route와 분리해 안전하게 제공합니다

rustee-static은 one explicit filesystem root와 URI prefix를 연결하는 Tower layer입니다. CDN, object storage, reverse proxy를 대체하려 하지 않으며, 작은 origin delivery 경계를 예측 가능하게 제공합니다.

사용 경계

let files = StaticFiles::new("./public")?
    .at("/assets")?
    .with_cache_control(HeaderValue::from_static("public, max-age=3600"))
    .with_max_file_bytes(256 * 1024 * 1024)?
    .with_streaming_threshold(256 * 1024)?
    .with_precompressed_variants(true);

let service = app.layer(files.layer());

layer는 /assets 아래의 GET과 HEAD만 먼저 처리합니다. 다른 prefix와 method는 inner application service로 그대로 전달합니다. default mount는 /static, default cache policy는 no-store, default maximum file size는 8 MiB입니다. with_streaming_threshold는 기본적으로 꺼져 있으므로, 큰 file을 제공하려면 maximum admission limit와 streaming threshold를 함께 명시합니다.

Byte range

Range: bytes=start-end, bytes=start-, bytes=-suffix set을 지원합니다. 하나의 satisfiable range는 206과 top-level Content-Range, 선택한 길이의 Content-Length를 반환하며, end가 파일 끝보다 크면 끝으로 clamp합니다. HEAD도 같은 206 header와 빈 body를 반환합니다.

  • syntax가 malformed이거나 모든 member가 unsatisfiable이면 416과 Content-Range: bytes */length를 반환합니다. 하나라도 satisfiable이면 unsatisfiable member는 제외합니다.
  • overlap/adjacent member는 sort 후 merge합니다. 하나만 남으면 single 206이며, 둘 이상이면 multipart/byteranges; boundary=... 206을 반환합니다. multipart top-level에는 Content-Range를 넣지 않고 각 part가 Content-Type/Content-Range를 가집니다.
  • 입력 member는 최대 64개, normalize 뒤 part는 최대 16개입니다. 이 limit를 넘거나 duplicate Range header를 보내면 416으로 거부합니다. multipart body는 threshold와 무관하게 bounded file chunk로 stream합니다.
  • If-None-Match가 현재 representation과 일치하면 Range보다 먼저 304를 반환합니다.
  • If-Range는 current Last-Modified HTTP-date가 정확히 일치할 때만 single 또는 multipart 206을 유지합니다. 현재 ETag는 weak metadata validator이므로 ETag 기반 If-Range는 full 200으로 되돌립니다.

Precompressed variants

with_precompressed_variants(true)를 명시했을 때에만 non-Range request에서 logical asset의 sibling .br 또는 .gz 파일을 선택합니다. 예를 들어 app.js에는 app.js.br, app.js.gz가 대응합니다. Accept-Encoding quality를 따르며 동률이면 Brotli를 우선하고, 선호한 파일이 없으면 다음 허용 encoding 또는 identity file로 fallback합니다.

  • encoding header가 없거나 br/gzip quality가 0이면 identity file을 반환합니다.
  • non-Range response는 variant 유무와 관계없이 Vary: Accept-Encoding을 포함합니다.
  • 선택된 variant의 Content-Length, weak ETag, Last-Modified를 사용하고 Content-Encoding을 설정합니다. Content-Type은 logical asset extension으로 결정합니다.
  • Range request는 항상 identity representation으로 처리합니다. 따라서 single/multipart 206과 416 response에는 variant coding이나 encoding Vary를 붙이지 않습니다.
  • variant path도 canonical root, regular-file, size-limit 검사를 통과해야 합니다. sibling이 root 밖을 가리키는 symlink면 사용하지 않습니다.

Large-file streaming

with_streaming_threshold를 설정하면 threshold 이상인 selected representation을 bounded async file chunk로 읽습니다. full 200과 single-range 206 모두 적용하며, HEAD는 file body를 열지 않습니다. stream은 response body가 실제로 전송될 때만 소비되므로 client disconnect가 file read를 자연스럽게 취소합니다.

  • with_max_file_bytes는 여전히 canonicalized regular file의 admission upper bound입니다. threshold만 높인다고 그 limit를 넘는 file이 허용되지는 않습니다.
  • Content-Length, Content-Range, cache validator와 Accept-Ranges는 metadata에서 계산하므로 buffered response와 같은 HTTP contract를 유지합니다.
  • precompressed opt-in을 함께 쓰면 선택된 .br/.gz representation의 길이로 threshold를 판정합니다. Range request는 기존처럼 identity representation을 stream합니다.
  • read 중 filesystem 오류가 나면 body stream은 오류로 종료됩니다. static layer는 file path detail을 response에 렌더하지 않습니다.

Filesystem security

  • root는 layer 생성 시 canonicalize하고 directory인지 확인합니다.
  • request segment는 strict percent decoding 뒤 ., .., slash, backslash, NUL을 거부합니다.
  • target도 canonicalize한 뒤 configured root 밖이면 거부하므로 symlink escape를 제공하지 않습니다.
  • directory listing, automatic index.html, generic file browser는 제공하지 않습니다.
  • assets가 application code와 다른 lifecycle을 가지면 CDN/object storage 또는 reverse proxy가 더 적절한 production boundary일 수 있습니다.

Conditional cache

성공한 GET/HEAD response는 file length와 nanosecond modification time으로 만든 weak ETag와 HTTP-date Last-Modified를 포함합니다. 이는 file body를 다시 읽어 hash하지 않고 origin cache revalidation을 가능하게 하는 metadata validator이며, byte-range validator나 content-addressed asset fingerprint가 아닙니다.

요청 조건현재 동작
If-None-Matchweak comparison으로 현재 ETag 또는 *가 일치하면 304를 반환합니다.
If-Modified-SinceIf-None-Match가 없을 때만 second-resolution Last-Modified와 비교합니다.
304 response빈 body와 Cache-Control, ETag, Last-Modified, representation의 Content-Encoding/Vary만 반환하며 Content-Type/Content-Length는 보내지 않습니다.

현재 제외 범위

  • directory index, SPA fallback, automatic cache fingerprint policy

dynamic gzip/Brotli compression은 response compression layer에서 제공합니다. precompressed variant에는 이미 Content-Encoding이 있으므로 compression layer가 재압축하지 않습니다.
